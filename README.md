# android-movie-ticket

## 기능 요구 사항
- 사용자는 영화 예매 시스템을 통해서, 보고 싶은 영화를 예매할 수 있음

## 1단계 - 영화 선택
### 영화 목록
- [x] 영화 목록에는 하나의 영화가 보인다.
- [x] 영화에는 포스터, 제목, 상영일 러닝타임, 지금 예매 버튼이 있다.
- [x] 지금 예매 버튼을 누르면 영화 예매 - 완료 화면으로 전환된다.
- [x] 영화 목록을 노출할 때 ListView를 사용한다.

### 영화 예매 - 완료
- [x] 영화 예매 화면 - 영화 예매 화면에는 '영화 상영 시작 시간 15분 전까지 취소가 가능합니다.' 멘트가 있다.
- [x] 영화 제목과 상영일이 있다.
- [x] 뒤로가기 버튼을 누르면 영화 목록 화면으로 전환된다.

## 2단계 - 영화 예매
### 영화 목록
- [x] 영화 목록에는 영화 상영 시작일과 종료일이 있다.

### 영화 예매 - 확인
- [x] 영화 포스터, 영화 타이틀, 상영일, 러닝타임이 있다.
- [x] 플러스, 마이너스, 선택 완료 버튼이 있다.
- [x] 예약할 인원이 있다.
  - [x] 예약할 인원은 최소값은 1이다.
  - [x] 예약할 인원이 1인데, - 버튼을 누르면, 토스트 메시지로 "1명이상 예매해야합니다."라는 메시지가 나온다.
- [ ] 날짜를 선택할 수 있다.
  - [ ] 기본값으로 초기화
- [ ] 시간을 선택할 수 있다.
  - [ ] 기본값으로 초기화
  - [ ] 영화 상영 시간 범위는 오전 9시부터 자정까지다.
  - [ ] 주말에는 오전 9시부터 두 시간 간격으로 상영한다.
  - [ ] 평일에는 오전 10시부터 두 시간 간격으로 상영한다.
- [x] 선택 완료 버튼을 누르면, 다이얼로그가 나온다.
  - [x] 다이얼로그에서 취소를 누르면 원래 화면으로 돌아간다.
  - [x] 다이얼로그에서 예매 완료를 누르면, 영화 예매 - 완료로 이동한다.
- [ ] 화면이 회전되어도 인원, 시간, 날짜는 유지되어야 한다.
  
### 영화 예매 - 완료
- [x] 예매한 상영 시간이 있다.
- [x] 예매한 인원 수가 있다.
- [x] 영화 예매 금액이 있다. ex) 13,000원(현장 결제)
- [x] 영화 예매 금액은 1인당 13,000원이다.
