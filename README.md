# android-movie-ticket

## 기능 요구 사항
- 사용자는 영화 예매 시스템을 통해서, 보고 싶은 영화를 예매할 수 있음

### 영화 목록
- [ ] 영화 목록에는 하나의 영화가 보인다.
- [ ] 영화에는 포스터, 제목, 상영일 러닝타임, 지금 예매 버튼이 있다.
- [ ] 지금 예매 버튼을 누르면 영화 예매 - 완료 화면으로 전환된다.
- [ ] 영화 목록을 노출할 때 ListView를 사용한다.

### 영화 예매 - 완료
- [ ] 영화 예매 화면에는 '영화 상영 시작 시간 15분 전까지 취소가 가능합니다.' 멘트가 있다.
- [ ] 영화 제목과 상영일이 있다.
- [ ] 뒤로가기 버튼을 누르면 영화 목록 화면으로 전환된다.
