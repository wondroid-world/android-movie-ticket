# android-movie-ticket

## 기능 요구 사항
- 사용자는 영화 예매 시스템을 통해서, 보고 싶은 영화를 예매할 수 있음

## 1단계 - 영화 선택
### 영화 목록
- [x] 영화 목록에는 하나의 영화가 보인다.
- [x] 영화에는 포스터, 제목, 상영일 러닝타임, 지금 예매 버튼이 있다.
- [x] 지금 예매 버튼을 누르면 영화 예매 - 완료 화면으로 전환된다.
- [x] 영화 목록을 노출할 때 ListView를 사용한다.

### 영화 예매 - 완료
- [x] 영화 예매 화면 - 영화 예매 화면에는 '영화 상영 시작 시간 15분 전까지 취소가 가능합니다.' 멘트가 있다.
- [x] 영화 제목과 상영일이 있다.
- [x] 뒤로가기 버튼을 누르면 영화 목록 화면으로 전환된다.

## 2단계 - 영화 예매
### 영화 목록
- [x] 영화 목록에는 영화 상영 시작일과 종료일이 있다.

### 영화 예매 - 확인
- [x] 영화 포스터, 영화 타이틀, 상영일, 러닝타임이 있다.
- [x] 플러스, 마이너스, 선택 완료 버튼이 있다.
- [x] 예약할 인원이 있다.
  - [x] 예약할 인원은 최소값은 1이다.
  - [x] 예약할 인원이 1인데, - 버튼을 누르면, 토스트 메시지로 "1명이상 예매해야합니다."라는 메시지가 나온다.
- [x] 날짜를 선택할 수 있다.
  - [x] 기본값으로 초기화
- [x] 시간을 선택할 수 있다.
  - [x] 기본값으로 초기화
  - [x] 영화 상영 시간 범위는 오전 9시부터 자정까지다.
  - [x] 주말에는 오전 9시부터 두 시간 간격으로 상영한다.
  - [x] 평일에는 오전 10시부터 두 시간 간격으로 상영한다.
- [x] 선택 완료 버튼을 누르면, 다이얼로그가 나온다.
  - [x] 다이얼로그에서 취소를 누르면 원래 화면으로 돌아간다.
  - [x] 다이얼로그에서 예매 완료를 누르면, 영화 예매 - 완료로 이동한다.
- [x] 화면이 회전되어도 인원, 시간, 날짜는 유지되어야 한다.
  
### 영화 예매 - 완료
- [x] 예매한 상영 시간이 있다.
- [x] 예매한 인원 수가 있다.
- [x] 영화 예매 금액이 있다. ex) 13,000원(현장 결제)
- [x] 영화 예매 금액은 1인당 13,000원이다.

## 3단계 - MVP 리팩터링
- [x] 영화 목록
- [x] 영화 예매 - 확인
- [x] 영화 예매 - 완료

## 4단계 - 영화 목록
### 영화 목록
- [x] recyclerView로 변환
- [x] 영화 목록에 영화가 세 번 노출될 때마다 광고가 한번 노출
- [ ] 영화 목록의 요소는 10,000개까지 추가될 수 있다

### 영화 예매
- [x] 선택 완료를 누르면, 좌석 선택 페이지로 넘어간다.

### 좌석 선택
- [ ] 인원 수 만큼 좌석이 선택되면, 확인 버튼이 활성화된다.
- [ ] 활성화된 확인 버튼을 누르면 예매 확인 AlertDialog가 나온다.
- [ ] 예매 완료를 누르면, 영화 예매 - 완료 페이지로 넘어간다.
- [ ] 좌석을 선택하면 배경색이 바뀌고, 하단에 선택한 좌석 수를 반영한 최종 가격이 표시된다.
  - [ ] 선택된 좌석을 재선택하면 선택이 해제된다.
- [x] 좌석은 총 5행 4열로 구성되어 있고 각 행은 알파벳, 열은 숫자로 표현한다.
  - 1, 2행은 B등급, 보라색 글자로 표시한다. (10,000원)
  - 3, 4행은 S등급, 초록색 글자로 표시한다. (15,000원)
  - 5행은 A등급, 파란색 글자로 표시한다. (12,000원)

### 영화 예매 - 완료
- [x] 좌석이 나온다.
